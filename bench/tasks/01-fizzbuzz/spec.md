Write a wand function `fizzbuzz : Int -> String` that, given a positive
integer `n`, returns:

- `"FizzBuzz"` if `n` is divisible by both 3 and 5
- `"Fizz"` if `n` is divisible by 3 (but not 5)
- `"Buzz"` if `n` is divisible by 5 (but not 3)
- otherwise, the number itself as a string

Write only the function definition(s) needed — no example calls, no
top-level script, just `let fizzbuzz ... = ...`.
