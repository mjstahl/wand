Define a wand type `Point` with two named `Int` fields, `x` and `y`.

Write a function `manhattan : Point -> Point -> Int` that returns the
Manhattan distance between two points: `abs(x1 - x2) + abs(y1 - y2)`.
(There is no builtin `abs` — compute the absolute value yourself.)

Write only the type definition and function definition(s) needed — no
example calls, no top-level script.
