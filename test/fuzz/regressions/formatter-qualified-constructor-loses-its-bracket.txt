This is formatter-qualified-head-hides-a-constructor again. That fix kept
the wrong form.

The parser builds `p.M N` as `App (Qualified (p, M), N)`. It builds
`p.M(N)` as `Qualified (p, App (M, N))`. The earlier fix called these one
program with two spellings, and flattened the second into the first so the
constructor guard could see the constructor. They are two programs. The
bracket puts the payload inside the module:

  let foo = import ./foo   -- type Wrap = Boxed Colour, Colour = Red | Green
  foo.Boxed(Red)           -- typechecks: Red is read in foo
  foo.Boxed Red            -- type error: unknown constructor 'Red'

So every `p.M(N)` was written as `p.M N`, and the payload changed scope.
The formatter also did not settle:

  n d.M(N)(s[])  -->  n d.M N (s [])  -->  n (d.M) (N (s []))

A `Qualified` that holds an application keeps its bracket now. `flatten`
does not descend through `Qualified`. The payload stays in the
constructor's own bracket, so no guard is owed.
