# Signatures the fuzzer has found and that are not yet fixed. One per line,
# with a comment saying what it is. A line here keeps a nightly run green
# for a bug already written down -- it does not hide it: the summary counts
# every hit under "known, not failing".
#
# A line leaves when the bug is fixed. Where the fix goes depends on the
# finding. One that can be written as an ordinary test belongs in the
# ordinary suite. One that cannot, because the input is a byte sequence no
# person would write, goes into test/fuzz/regressions/ as the input itself.
#
# The reproducer is written out beside each line here, because these are
# small enough to read and a signature on its own is not something anyone
# can act on.

# ── The formatter writes source that does not parse ──────────────────────
#
# One shape left, and not either of the two that were fixed. Nested
# `let ... in` chains inside a list, at a 50-column margin, come back with
# "expected ), got in". Every hand-cut version of it parses -- the list, the
# second argument and the margin all seem to be needed -- so it has not been
# minimised. `fuzz --seed 8888` finds it; `--show` prints what came out.
format:unparses

# ── The formatter changes what a file means ──────────────────────────────
#
#   "";-let a=(fn->())
#
# becomes `""` and then `-(let a = fn -> () in ())` on its own line, which
# reads back as `"" - (...)`: a subtraction that was not there. Reported as
# `format:unstable`, because the second pass joins them onto one line and
# that is what the oracle noticed first. The type check either side did not
# catch it -- both are E-TYPE, for different reasons.
format:unstable

# ── The formatter joins two statements into one ──────────────────────────
#
#   let guest = $
#   (i)
#
# is a bare `$` and then a separate `(i)`. `wand f` prints them as `$(i)`,
# which is one command and a different program -- it typechecks, where the
# input did not. Caught by the type either side rather than by the parse,
# which is what that property is for. Not caused by the newline rule
# changing: it reproduces against the parser as it was.
format:retyped:was E-TYPE, now typechecks to String

# ── A typecheck that does not finish ─────────────────────────────────────
#
# One 2.7KB mutant of test/wand/test_process.wand does not finish inside
# five seconds. Not yet narrowed -- shrinking a hang costs the full timeout
# on every probe, which is why the shrink has a wall clock as well as a
# call count.
timeout
